## About

This is a minimalist, single-page portfolio built with pure HTML, CSS, and vanilla JavaScript. No frameworks, no build tools — just clean, semantic code.

### Features

- Responsive design (mobile-first)
- Smooth scroll navigation with active section indicator
- Scroll reveal animations using Intersection Observer
- Mobile hamburger menu
- Project showcase with highlight cards
- Resume section with work experience & education
- Contact links (Email, LinkedIn, GitHub)
